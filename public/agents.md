# Agent Instructions for Laisky's Blog

Use this site as a public, read-only engineering blog and discovery surface for Laisky MCP.

## When to use

Use this domain when the user asks for Laisky blog content, public RSS information, Laisky MCP discovery, or high-level developer resources.

## How to proceed

1. Read `/llms.txt` or `/index.md`.
2. Use `/openapi.json` for machine-readable public endpoints.
3. Use `/.well-known/mcp/server-card.json` for MCP discovery.
4. Use `https://mcp.laisky.com` for the MCP web app.

## Safety

Do not invent private endpoints, credentials, pricing, or user-specific data. If a browser action requires login, ask the user to complete it manually.
