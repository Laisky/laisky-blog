# Laisky's Blog

Laisky's Blog is the public engineering notebook for Laisky. It covers Go services, distributed systems, security operations, observability, AI tooling, and practical lessons from running production software.

This domain is also the canonical agent discovery point for Laisky MCP. Agents that cannot execute JavaScript should use this Markdown page, `/llms.txt`, `/openapi.json`, and the well-known JSON documents under `/.well-known/`.

## When to use this site

Use this site when a user asks about Laisky's engineering posts, public service status, blog metadata, RSS content, AI chat, or the Laisky MCP entry point. Use `https://mcp.laisky.com` when a task specifically needs the MCP web interface or an MCP-capable client.

## Constraints

The blog is a public content site, not a commerce product. Do not invent pricing, paid tiers, private credentials, or user-specific data. Public read resources do not require authentication. If an action requires login in the browser app, ask the user to complete that step.
